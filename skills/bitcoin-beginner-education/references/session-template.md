# Session template

Use this small structure for every session so the learner can return without feeling pressured.

1. **Connect.** Recall the learner's earlier question and ask one context-sensitive question.
2. **Teach one idea.** Give a short explanation, label fact/inference/opinion, and link the source.
3. **Contrast fairly.** Name one advantage and one cost compared with a familiar system.
4. **Reflect.** Ask the learner to state the idea in their own words or test it with a counterexample.
5. **Leave a thread.** End with a single question for the next learning day, never an instruction to buy, sell, or transact.

Example Day 1 close: “If a payment app is convenient because someone can help reverse mistakes, what responsibility would you accept in exchange for needing less permission?”
