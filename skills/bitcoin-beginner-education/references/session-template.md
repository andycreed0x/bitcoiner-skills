# Guided session template

Use this template only when the learner asks for a deeper explanation or an ongoing learning path. A narrow, direct question should be answered without this sequence.

1. **Orient, if needed.** Ask one context question only when the answer would change the next explanation.
2. **Teach one idea.** Lead with the central thesis, explain one concept, and label or link a fact, inference, or opinion as needed.
3. **Contrast fairly.** Name one benefit and one cost compared with a familiar system. Use an original systems analogy only if it makes the distinction clearer.
4. **Test a premise, if useful.** Ask one respectful question about a belief the learner actually expressed, or ask for a plain-language restatement. Skip this step when it adds no value.
5. **Leave a thread, if wanted.** Offer two or three next topics only when the learner wants to keep exploring. Never use this as pressure to buy, sell, or transact.

## Microexamples

### Absolute beginner

**Idea:** “Una cuenta bancaria se parece a una entrada en el libro de una institución; Bitcoin permite que las claves autoricen el movimiento sin que esa institución mantenga la cuenta. Eso ofrece más control, pero también traslada la responsabilidad de proteger las claves.”

**Optional next thread:** “Podemos seguir por custodia, escasez o cómo se verifican las reglas. ¿Cuál te interesa?”

### Trader who equates price with the monetary thesis

**Idea:** “El precio mide cuánto está pagando el mercado hoy; la tesis monetaria pregunta qué reglas, riesgos de contraparte y propiedades de custodia tiene el activo. Son preguntas relacionadas, pero no son la misma pregunta.”

**Optional challenge:** “Si el precio subiera por especulación mientras las reglas monetarias empeoraran, ¿dirías que la tesis se fortaleció o se debilitó?”

### Technical learner who assumes decentralization eliminates risk

**Idea:** “La descentralización reduce la dependencia de un operador único, como una red con muchos validadores en lugar de una base de datos administrada por una empresa. No elimina riesgos de software, conectividad, regulación ni custodia.”

**Optional next thread:** “Podemos profundizar en consenso, autocustodia o censura. ¿Por cuál seguimos?”
