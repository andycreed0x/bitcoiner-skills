# bitcoiner-skills

Markdown-first skills for AI agents that need to discuss Bitcoin carefully.

## Available skills

- [`bitcoin-beginner-education`](skills/bitcoin-beginner-education/SKILL.md) — a source-backed, multilingual learning guide for absolute Bitcoin beginners. It teaches concepts and questions; it does not execute transactions or give personalized investment advice.

Each skill keeps its operating instructions and its reference material together so that claims can be checked at the point of use.
